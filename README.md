# Sugarless Shenanigans

Upload `index.html` and the complete `assets` folder to the root of your GitHub repository. Keep the filenames and folder structure unchanged.

Then open **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

The interactive chocolate bar is a real Three.js model built from 3D geometry (not a flat image). It can be rotated by dragging and zoomed with the scroll wheel/pinch. The ingredient button opens the ingredient panel.

The logo is `assets/sugarless-shenanigans-logo.png`. The dark chocolate background is `assets/chocolate-background.png`.

Note: this is a product concept, not a validated nutrition formula. Ingredient quantities, nutrition values, vitamin/mineral levels, allergen declarations and marketing claims need professional review and testing before sale.
